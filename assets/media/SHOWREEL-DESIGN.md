# CodeSage — Clear Signal

15 seconds · 1920 × 1080 · 60 fps · README showreel.

## Visual identity

An editorial engineering film: oversized condensed typography, warm-white
letterforms on graphite, chartreuse packets moving through finely drawn circuits.
Motion explains causality: dispatch, exclusive lease, heartbeat renewal, fenced
commit, coherent planning, parallel investigation, evidence convergence. A single
ring motif becomes a lease seal, investigation aperture, then a metric arc.
The mood is fast, confident and precise. No stock footage or invented dashboards.

## Palette and typography

- Graphite `#101510`: background.
- Paper `#F2F2E8`: principal text.
- Signal `#D3F86A`: valid owner, active reasoning and benchmark Precision.
- Sage `#9BA993`: secondary labels and structure.
- Terracotta `#ED947D`: stale owner / rejected commit only.
- Barlow Condensed, bold: display; IBM Plex Mono: identifiers and numbers.
- Microsoft YaHei / Noto Sans CJK SC: brief Chinese explanatory text.

## Factual constraints

- Delivery does not itself grant ownership. Lease identity and fencing protect commits.
- A stale Worker may still execute; its commit is rejected. Do not claim exactly-once execution.
- Deep Review currently runs independently of the Worker path. Both audit scenes
  carry a legible “独立运行 · Worker 接入待完成” badge. The transition is editorial,
  never an asserted live integration.
- Reviewer lanes illustrate dynamically planned questions, not fixed security /
  architecture / quality roles, and not a fixed number of deployed Reviewers.
- Semantic is a lead, not verified truth. Planner assigns work, not predicted defects.
- Cross uses candidate evidence and on-demand code to verify/challenge/connect.
- Report the supplied run's semantic metrics, not a general performance guarantee.
  Source: `aacr-bench-main/evaluation/metrics/aacr_bench/codesage_deep/deep-GLM-5.2/metrics_codesage_deep_20260928_085915.json`.
- Counts/lease epochs in process graphics are illustrative, not production telemetry.

## Build

HyperFrames motion and hierarchy guidance informs the visual treatment. Remotion
provides deterministic frame-based composition, separately editable scenes and MP4
rendering. Original synthesized sound accompanies the movie; all meaning remains
legible with sound muted. Keep implementation isolated from application dependencies.
