# Spec: 阶段 02 — LLM 客户端

> 分支:`feat/02-ai`。依据主规格 `docs/specs/codesage.md`(阶段 02)。

## Objective

LLM 客户端是 harness 的「模型运输层」:统一的消息/工具格式翻译成各提供商的请求与流式响应,管理模型指针解析、自管重试、成本核算、VCR 录制回放。引擎主循环(阶段 06)只面对一个内部规范,不感知提供商差异。

## 对照保留清单

- #11 模型指针 main/task/compact/quick + 辅助请求失败回退 main;自管重试(尊重 retry-after),禁用 SDK 重试
- #12 内部消息形状统一(Anthropic 式 content blocks 为规范契约),OpenAI 侧转换;token 归一化只在边界一次

## 范围

**做**:
1. 内部消息规范:ContentBlock(text/thinking/tool_use/tool_result)、Message、LLMRequest/Response、Usage、StreamEvent
2. OpenAI 兼容 adapter(Chat Completions:DeepSeek/Qwen/GLM 通用,含 reasoning_content 与工具调用增量、usage 归一化含 DeepSeek cache 分区)
3. Anthropic 原生 adapter(httpx 手写,SSE 流式)
4. LLMClient:模型指针解析(GlobalConfig.model_profiles/pointers)、自管重试(429/5xx + retry-after)、辅助请求失败回退 main、错误分类
5. 成本核算(单价表 + 缓存命中 10% 计价)
6. VCR 录制/回放(sha1 指纹 → fixture)

**不做**:上下文组装与压缩(阶段 06/10);多模型并发编排(阶段 18);受限客户端降级伪装链(Kode 的 compat 方案,安全领域适配阶段再议);模型切换 UI。

## Commands

```bash
pytest tests/ -q                        # 全量单测(全部离线:MockTransport/VCR)
CODESAGE_VCR=replay pytest tests/ -q    # VCR 回放模式
```

## Code Style

主规格风格;适配器以 httpx.AsyncClient 传输,全链路支持 AbortSignal(调用方可取消流)。

## Testing Strategy

- 全离线:httpx MockTransport 模拟 SSE 流与非流式响应;不依赖真实 API key
- retry:429/5xx/超时分别断言重试次数与 retry-after 尊重
- VCR:录制 mock 响应 → 回放断言一致(机制本身可测)
- 集成测试(真实 key)沿用 conftest 模式:无 key 自动 skip —— 本阶段无真实 key 则不写,阶段 06 验收时补一条真实链路测试

## Boundaries

- **Always**: 适配器输出必须过内部规范;usage 归一化在边界一次;流事件必须有 done 事件
- **Ask first**: 新增 HTTP 依赖;调整消息规范字段
- **Never**: 在 adapter 里做业务逻辑(重试/回退都在 client);打印或记录 API key

## Success Criteria

- [ ] 内部规范定型,OpenAI/Anthropic 双 adapter 转换正确(含流式工具调用增量)
- [ ] 重试尊重 retry-after;辅助请求失败自动回退 main(可恢复错误清单)
- [ ] 成本核算含缓存命中;usage 归一化(DeepSeek cache 分区)单测覆盖
- [ ] VCR 录制/回放一致性
- [ ] 全量单测绿,无网络依赖
