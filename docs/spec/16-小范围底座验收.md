# 16 小范围底座验收实施规格

## 边界

只改快速 PR 审查的执行控制面：运行身份、执行上下文、阶段结果、产物引用、任务级 lease、取消／恢复／重复投递语义，以及可复现的本地验收入口。三视角提示词、模型参数、QueryLoop、SessionStore 和对外 API 形状保持不变。

## 模块落点

- `app/services/contracts/review_execution.py`：四个纯 Pydantic 契约及身份指纹辅助函数，不依赖 ORM、API 或 worker。
- `app/services/pr_review/artifacts.py`：run 级本地产物存取、路径边界和 SHA-256 校验。
- `app/models/review_execution.py`：`review_execution_runs` 一对一任务执行记录。
- `app/services/pr_review/execution_ownership.py`：基于行锁和数据库时间的初始化、领取、续租、取消、恢复及 epoch 校验。
- `app/services/pr_review/execution.py`：`execute_quick_review(task_id, dependencies)` 应用服务入口。
- `alembic/versions/20260906_01_add_review_execution_runs.py`：新表迁移。
- `tests/worker_acceptance/` 与一键脚本：真实 PostgreSQL、Redis、两个 ARQ worker 的隔离验收。

## 不变量

1. 首次执行持久化身份；resume 只读取该身份，绝不重新生成 `run_id`。
2. Git 输入缺少固定 base/head 时拒绝建立身份；diff 输入允许两个 SHA 为空。
3. 领取、续租和提交都携带 `lease_epoch`；旧 owner 的 epoch 不匹配时拒绝。
4. 取消标志先提交到数据库，本地取消只作加速；取消后禁止完成提交。
5. resume 清除取消标志、生成新 delivery id；队列 job id 使用 delivery id，避免 ARQ 结果保留去重。
6. `StageResult` 是阶段快照的规范载荷；completed 只由现有完成门禁之后写入。
7. 输入 diff 和最终 JSON 都写为 `ArtifactRef`；加载时重算哈希和大小。
8. 产物路径只允许 run 根下相对普通文件，拒绝绝对路径、`..` 和符号链接越界。

## 验证

先运行并保留既有基线失败；新增契约、产物和 ownership 单测使用隔离临时目录／数据库。集成组必须显式连接 PostgreSQL 与 Redis，不得回退 SQLite 或内存队列；Docker 或依赖不可用时报告阻塞而非伪造通过。
