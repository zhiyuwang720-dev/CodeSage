## 2. 阶段 20 战略转向(本版核心)

不再按「复刻 Claude Code」路线继续,转向价值锚点:**能理解复杂项目的 CodingAgent** ——
陌生代码库自动建图谱、基于影响面分析强制最小 diff、ponytail 阶梯融入引擎行为。

- **执行前拦截**(阶段 20 修正):写操作(Write/Edit)在权限闸之后、执行之前拦一次,
  「最好的代码是从未写过的代码」;同一目标拦一次、重试放行;错误码 `minimal_change_blocked`
  独立于 `permission_blocked`,sibling 豁免语义同步扩展
- **intel 三文件生产级重写**:`service.py`(ToolCaller seam + 结构化解析 + 分级错误 + LRU 缓存 +
  后台索引不阻塞启动)、`minimal_change.py`(多场景建议契约 + fail-open 顺序)、`ponytail.py`(全文 +
  模式状态机 off/lite/full/ultra + 6 技能 + 注入钩子)
- **KVCache 探查结论**:缓存命中率是 API 侧前缀缓存(公式与 UI 数据流已解析,启示:保持系统 prompt
  跨轮稳定可提升命中率;CodeSage 数据已具备,可照抄公式显示)
